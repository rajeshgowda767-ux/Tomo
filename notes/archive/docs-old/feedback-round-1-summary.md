# Tomo Mobile Beta 1 Feedback Summary

Status: Feedback capture for Beta 2 planning

## Keep

- Users understood Tomo helps decide what to cook.
- Mood board was noticed.
- Pantry was highly appreciated.
- Shopping Cart was useful.
- Collections worked well.
- Color palette was liked.

## Fix

- Users want cooking instructions / how to make it.
- Some users saw repeated placeholder images.
- Pantry suggestions disappear when more ingredients are selected.
- One user thought it might be food delivery.

## Investigate

- Veg / non-veg filters.
- Gym Foods naming.
- Recipe quantities / servings.
- Regional expansion.
- User onboarding clarity.

## Ignore For Now

- Grocery app integrations.
- Full meal planner.
- Login.
- Paid plans.
- AI copilot.
- Community features.

## Beta 2 Planning Notes

- Keep Tomo's core decision-helper positioning clear.
- Prioritize practical cooking confidence over large new surfaces.
- Treat Pantry trust and cooking instructions as the most important Beta 2 improvements.
- Preserve the existing Mobile RC1 work while exploring changes on `beta-2-development`.
