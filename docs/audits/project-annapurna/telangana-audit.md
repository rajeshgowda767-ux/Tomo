Audited active recipes associated with Telangana, Hyderabad, Hyderabadi cooking, Nizam-influenced dishes and shared Andhra & Telangana records.

Beta 3 Telangana implementation should focus on clear Hyderabadi/Telangana identities. Generic biryani should not be renamed unless the ingredients and quick guide show a true dum/layered Hyderabadi profile. The current `Chicken Biryani` record does match that profile, so it is safe to canonicalize as `Hyderabadi Chicken Biryani`. `Hyderabadi Dum Biryani`, however, should be added as a distinct recipe per the canonical rule.
