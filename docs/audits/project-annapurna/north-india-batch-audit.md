# Project Annapurna - North India Batch Audit

## 1. Executive Summary

Audited Punjab, Haryana, Himachal Pradesh, Uttarakhand, Jammu & Kashmir and Ladakh.

- Total recipes audited: 15 direct/shared North India rows before implementation
- Approved renames: 0
- Approved additions: 35
- Recipe fixes required: 5
- Needs local review: 8
- Rejected / do not implement: 6

Punjab already had the strongest coverage. Haryana, Himachal, Uttarakhand, Jammu & Kashmir and Ladakh needed dedicated regional anchors. Shared dishes such as Thukpa and Bajra Khichdi were handled as aliases/shared notes, not duplicated.

## 7. Ladakh Summary

Approved additions: Skyu, Chutagi, Butter Tea.

## 8. Final Validation Decisions

### Approved Renames

None.

### Approved New Dishes

35 total across the six states.

### Recipe Fix Required

- Generic Chole Chawal should not become Amritsari Chole.
- Existing Thukpa is shared Himalayan/Northeast; do not duplicate for Ladakh.
- Existing Bajra Khichdi remains shared Rajasthan/Haryana.
- Generic Kadhi Chawal should not become Punjabi Kadhi Pakora.
- Generic Dum Aloo, if present later, should not become Kashmiri Dum Aloo without recipe match.

### Needs Local Review

- Himachali Dham-specific sequencing for Madra/Babru/Aktori.
- Ladakhi handling of Thukpa vs Skyu vs Chutagi in future collections.
- Jammu vs Kashmir naming notes for some dishes.
- Haryana ownership for Missi Roti and Bajra Khichdi shared with Punjab/Rajasthan.

### Rejected

- Duplicate Thukpa for Ladakh.
- Duplicate Bajra Khichdi for Haryana.
- Rename Chole Chawal to Amritsari Chole.
- Rename generic Kadhi Chawal to Kadhi Pakora.
- Regionalize generic North Indian recipes without matching method.
- Touch previous Project Annapurna state work.

## 9. Beta 3 Safe Implementation

Implemented only green items. No engines, pantry intelligence, scoring, ranking, analytics, pairings or UI changed.
