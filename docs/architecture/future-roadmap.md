# Future Roadmap

This document tracks future work that builds on the locked Beta 3 architecture.

The intelligence platform should remain unchanged unless audits fail.

## Future Work

- Image generation and image replacement for remaining placeholder recipes.
- Mobile UI polish.
- Regional recipe expansion.
- Seafood expansion.
- Rajasthan coverage.
- New collections.
- Additional recipe-family expansion.
- More substitution records when real cooking swaps are validated.
- Additional content for content gaps reported by audits.
- Beta 4 user feedback.

## Architecture Rule

Future work should extend records, recipe data, UI surfaces, and audits. It should not redesign the locked Beta 3 intelligence behavior unless a new architecture version is created.
