# Tomo Beta 3 Architecture Lock

## Status

LOCKED

## Purpose

The Beta 3 intelligence platform is complete. Future work should extend it, not redesign it.

## Locked Systems

- Recommendation Engine
- Pantry Intelligence V3
- Ingredient Knowledge Platform
- Ingredient Relationship Graph
- Flavor Graph
- Regional Ingredient Matrix
- Seasonal Intelligence
- Ingredient Substitution Engine
- Explainability Engine
- Knowledge Bridges
- Pairings Engine
- Metadata Integrity
- Recipe Authoring
- Collections Engine

## Modification Policy

Changes are allowed only if:

- A production bug is discovered.
- An audit fails.
- A new ingredient is introduced.
- A new recipe family is introduced.
- Catalog expansion requires knowledge expansion.

Core engine behavior must not be redesigned inside Beta 3. Any redesign belongs in a new architecture version.
